# M2 original tactical asset set

M2 replaces the legacy geometry and character rigs with original NIGHTCELL 7
models. It preserves the approved C7 first-person rifle, field case and low cover,
and consolidates three redundant legacy files. There are **28 runtime GLBs** for
all 31 former inventory entries. `replacements.json` records the complete mapping.
No Synty mesh, palette atlas, Quaternius mesh or MoCap animation is loaded or
recovered by this pipeline. Historical licenses remain recorded in PROVENANCE.md.

## Build

Requires Blender 4.5 LTS, Node 22+, ffmpeg and the repository's pnpm dependencies.
The small glTF optimizer has isolated dependencies:

```sh
npm ci --prefix tools/art/full-set --workspaces=false --ignore-scripts
BLENDER=/path/to/blender pnpm assets:build --models-only
BLENDER=/path/to/blender pnpm assets:build --textures-only
node tools/art/full-set/validate.mjs
BLENDER=/path/to/blender pnpm assets:build --manifest-only --previews
node tools/art/modern/make-overview.mjs /path/to/chromium
node tools/art/modern/smoke.mjs /path/to/chromium
```

`generate.py` creates metre-scale GLBs, editable Blender scenes, material slots,
collision proxies and sockets under `build/modern-art`. It uses the original
primitive/weapon helpers in `tools/art/tactical-sample/generate.py`; it never
imports an existing GLB or rig. `--only m2_name,...` is useful for local iteration;
the published build always regenerates the complete set.

`preview.py` renders the exported geometry with the same shared surfaces as the
runtime. These neutral studio plates are asset reviews, not gameplay screenshots.
`smoke.mjs` starts a local development server, uses the real demo input/rendering
path, and records a combat frame and report. Its inspection hook is omitted from
production builds. For headless environments with unreliable native pointer lock,
pass `--pointer-lock-adapter`; this adapts cursor capture and sends DOM mouse events; the resulting
report explicitly records that native pointer lock was not validated. Rendering,
input handlers, hitscan and damage still use the game code. `tools/art/capture.mjs` produces the website gallery from the
production build.

## Surfaces

The two files in `textures/` are original generated raster sources, committed so
the build does not require an image-generation service. Built-in image generation
was used on 2026-09-16; the complete prompts are in `texture-prompts.md`. Outputs
were encoded as 1024-square WebP, quality 83. No external asset URL is used at
runtime. Other surface data is generated by `tools/art/textures/generate.py`.
Normal/albedo maps use WebP quality 88; packed occlusion/roughness/metallic data
uses quality 70. Only concrete, steel, rubber and the environment are retained
from that shared surface generator; unused legacy palettes are removed.

All runtime models and textures use `m2_` filenames. The service worker uses
`nc7-content-m2` and removes only the old `nc7-content` cache on normal activation.
It does not force a service-worker update while someone is playing.
